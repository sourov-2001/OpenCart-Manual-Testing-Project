# OpenCart Manual Website Testing Project

A professional **Manual Website Testing Portfolio Project** built to validate the functionality of the **OpenCart Demo E-Commerce Website** through structured manual testing.

This project demonstrates practical QA documentation, organized website testing and real-world testing scenarios suitable for a **Junior SQA Engineer Portfolio**.

---

## Project Overview

The project focuses on validating the core functionality of an e-commerce website through manual testing.

The testing includes:

* Home Page Testing
* Header Testing
* Product Search
* Category Navigation
* Product Page Testing
* Add to Cart
* Shopping Cart
* Wishlist
* Product Compare
* Checkout Flow
* My Account
* Footer Validation
* Bug Reporting
* Requirement Traceability

---

## Website Under Test

**OpenCart Demo Store**

https://demo.opencart.com/en-gb?route=common/home

## Testing Workflow

1. Open the OpenCart Demo website.
2. Execute Home Page validation.
3. Verify Header functionality.
4. Test Search scenarios.
5. Validate Categories.
6. Verify Product Page.
7. Test Add to Cart.
8. Validate Shopping Cart.
9. Test Wishlist.
10. Test Product Compare.
11. Execute Checkout validation.
12. Verify My Account features.
13. Execute Footer validation.
14. Record bugs.
15. Update RTM.
16. Complete documentation.
